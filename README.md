# Lumi Player · Mac e Windows

File d'installazione di **Lumi Player** per computer. Sito e istruzioni: **https://getlumiplayer.pro**

- **Mac** (Intel e Apple Silicon): `Lumi-Player-mac.dmg`
- **Windows** 10/11 (64 bit): `Lumi-Player-windows.exe`

Scaricali dalla pagina [Releases](../../releases/latest).

Le app non sono firmate con un certificato a pagamento: la prima volta il sistema mostra un avviso.
- **Mac:** apri il file, trascina Lumi in Applicazioni, poi *Impostazioni di Sistema › Privacy e sicurezza › Apri comunque*.
- **Windows:** nella finestra di SmartScreen scegli *Ulteriori informazioni › Esegui comunque*.

Lumi è solo un lettore: non include né fornisce alcun contenuto.
